Import historical OHLCV

Select one combined CSV or multiple daily bhavcopy files

⇧
The importer recognizes standard OHLCV CSVs and common NSE old/new bhavcopy columns. If a Series column exists, only EQ rows are imported. Comma-grouped numeric cells must be quoted by the CSV, e.g. "1,50,000". Prefer YYYY-MM-DD or DD-MMM-YYYY; ambiguous slash and numeric dash dates are rejected. Large close-to-close moves trigger a corporate-action/data warning but are not adjusted. Demo prices are synthetic and never evidence of profitability.

Using EDGE NSE

1. Load historical OHLCV data from a licensed source.

2. Review structural validation warnings and scan candidate setups.

3. Use the risk calculator to plan a trade, then log it as paper-only.

4. Validate strategy performance in the separate Python backtesting project.
