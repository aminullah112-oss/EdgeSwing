Setup checklist

Set KITE_API_KEY, KITE_API_SECRET and APP_ACCESS_KEY as private environment variables on the backend host. Register https://your-backend/auth/callback as the redirect URL in the Kite developer console. Zerodha sessions expire daily, so connect again each trading day. Never commit .env. Start with a small symbol batch, validate data and indicator outputs, then expand to all NSE 500. Historical requests must be scheduled/throttled; do not fire 500 requests at once.
